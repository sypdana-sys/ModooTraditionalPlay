# 사방치기 VR 구현 체크리스트

## 기준과 사용 방법

- 세부 구현은 `Assets/Script/사방치기규칙_구체화.txt`를 우선 기준으로 한다.
- 전체 체험 방향과 확장 후보는 `Assets/한국 전통놀이 VR 체험 기획서.pdf`를 참고한다.
- 체크는 Unity Play Mode에서 해당 동작을 확인한 뒤 완료로 변경한다.
- 현재 `Map`과 `SabangStone`에 프로토타입이 있어도 Inspector 연결과 Play Mode 검증 전에는 완료로 표시하지 않는다.

## 필수 구현 항목

### 1. 게임 시작과 공통 상태

- [ ] 시작 UI에서 게임 시작을 선택하면 플레이어를 SpawnPoint로 이동한다.
- [ ] 준비, 위치 선택, 파워 선택, 투척, 전진, 회전, 복귀, 망 줍기, 라운드 완료, 땅따먹기, 클리어 상태를 관리한다.
- [ ] 플레이 중 일반 이동 입력을 잠근다.
- [ ] 목표 칸을 1번부터 8번까지 순서대로 관리한다.
- [ ] 전체 실패 횟수와 플레이 시간을 기록한다.

### 2. 놀이판과 구역 판정

- [ ] 1번부터 8번까지의 Tile Collider를 판정한다.
- [ ] 하늘 구역을 구분한다.
- [ ] Border Collider와 망의 경계선 접촉을 판정한다.
- [ ] 각 칸에 LandingPoint를 배치하고 이동에 사용한다.
- [ ] 게임 시작 SpawnPoint와 땅따먹기 투척 위치를 배치한다.
- [ ] 1·2·3·6번 외발 칸과 4·5번, 7·8번 양발 칸의 속성을 정의한다.
- [ ] 나란한 칸에서 왼쪽은 왼손, 오른쪽은 오른손에 대응한다.

### 3. 망 위치 선택과 투척

- [ ] 오른손 컨트롤러 Ray로 현재 목표 칸 내부 위치를 가리킨다.
- [ ] 목표 칸 밖 또는 경계선 근처에서는 위치를 확정할 수 없게 한다.
- [ ] 첫 Trigger 입력으로 망의 목표 위치를 확정한다.
- [ ] 0부터 100까지 왕복하는 파워 게이지를 표시한다.
- [ ] Trigger를 놓았다가 다시 누르면 현재 파워를 확정한다.
- [ ] 1번부터 8번까지의 필요 파워와 기본 허용 범위 ±10을 설정한다.
- [ ] 파워 부족, 적정, 초과에 맞는 실제 투척 비행을 보인다.
- [ ] 망 중심이 목표 칸 안에 있는지 판정한다.
- [ ] 망이 경계선에 접촉했는지 판정한다.
- [ ] 적정 파워, 목표 칸 착지, 경계선 미접촉을 모두 만족할 때만 성공 처리한다.
- [ ] 파워가 허용 범위를 벗어나면 목표 칸에 떨어져도 실패 처리한다.
- [ ] 실패 시 투척 모션을 끝까지 보인 뒤 실패 UI를 표시한다.
- [ ] 실패 후 같은 목표 칸의 위치 선택 단계부터 다시 시작한다.
- [ ] 실패 횟수는 투척 시도당 한 번만 증가한다.
- [ ] 성공 시 전진 QTE를 시작하는 이벤트를 호출한다.

### 4. 전진 이동 QTE

- [ ] QTE 기준점의 ±0.25초를 성공 구간으로 판정한다.
- [ ] 외발 칸에서 왼손 또는 오른손 Trigger 하나를 성공 입력으로 처리한다.
- [ ] 외발 칸에서 양손 동시 입력은 실패 처리한다.
- [ ] 양발 칸에서 양쪽 Trigger가 0.2초 이내에 눌리면 성공 처리한다.
- [ ] QTE 성공 시 다음 LandingPoint로 이동한다.
- [ ] QTE 실패 시 현재 칸의 QTE만 재시작한다.
- [ ] 목표가 1·2·3·6번이면 해당 칸 전체를 건너뛴다.
- [ ] 목표가 4번이면 5번 칸에 오른손 외발 입력으로 착지한다.
- [ ] 목표가 5번이면 4번 칸에 왼손 외발 입력으로 착지한다.
- [ ] 목표가 7번이면 8번 칸에 오른손 외발 입력으로 착지한다.
- [ ] 목표가 8번이면 7번 칸에 왼손 외발 입력으로 착지한다.

### 5. 회전, 복귀와 망 줍기

- [ ] 전진 마지막 구역에서 회전 QTE를 표시한다.
- [ ] 양쪽 Trigger가 0.2초 이내에 눌리면 회전 QTE에 성공한다.
- [ ] 회전 성공 시 XR Origin을 놀이판 출구 방향으로 180도 회전한다.
- [ ] 복귀 경로를 전진 경로의 역순으로 생성한다.
- [ ] 망이 있는 칸 바로 앞에서 망 줍기 안내를 표시한다.
- [ ] Grip 입력으로 망을 플레이어 손으로 자동 이동시킨다.
- [ ] 망을 줍기 전에는 다음 복귀 QTE로 진행할 수 없게 한다.
- [ ] 망을 든 상태로 남은 칸을 통과해 놀이판 밖으로 나오면 라운드를 완료한다.

### 6. 라운드 완료와 땅따먹기

- [ ] 라운드 성공 시 목표 칸을 1 증가시키고 다음 라운드를 시작한다.
- [ ] 8번 목표 라운드까지 성공하면 땅따먹기 단계로 전환한다.
- [ ] 땅따먹기 시작 시 플레이어를 1번 칸 앞의 지정 위치로 이동시킨다.
- [ ] Trigger 파워 게이지로 땅따먹기 망 투척을 처리한다.
- [ ] 1번부터 8번 중 경계선에 닿지 않은 착지 칸을 자기 땅으로 확정한다.
- [ ] 땅따먹기 실패 시 즉시 다시 시도한다.
- [ ] 자기 땅 칸의 색상 또는 문양을 변경한다.
- [ ] 첫 번째 자기 땅을 획득하면 게임 클리어 처리한다.
- [ ] 클리어 UI에 완료 시간과 전체 실패 횟수를 표시한다.
- [ ] 다시 하기에서 목표 칸, 망 위치, 자기 땅, 시간, 실패 횟수를 초기화한다.

## 필수 항목 검증

- [ ] Inspector에 Map, Rigidbody, Collider, Throw Point, Ray Origin, 입력 Action, UI, Layer Mask 참조를 연결한다.
- [ ] 1번부터 8번까지 목표 칸별 투척 성공을 확인한다.
- [ ] 파워 부족, 적정, 초과 투척의 착지와 결과를 확인한다.
- [ ] 경계선 접촉, 다른 칸 착지, 놀이판 밖 착지를 실패로 확인한다.
- [ ] 실패 후 동일 목표 칸을 다시 선택할 수 있는지 확인한다.
- [ ] 외발, 양발, 목표 칸이 있는 양발 구역의 QTE를 각각 확인한다.
- [ ] 회전, 복귀, 망 줍기, 라운드 완료를 한 번의 전체 플레이로 확인한다.
- [ ] 8번 라운드 이후 땅따먹기와 클리어, 다시 하기를 확인한다.
- [ ] VR HMD에서 이동과 회전이 불편하거나 멀미를 유발하지 않는지 확인한다.

## 이후 권장 항목

### 플레이 경험과 조정

- [ ] 파워 게이지 속도, 칸별 필요 파워, 허용 범위를 플레이 테스트로 조정한다.
- [ ] QTE 속도와 성공 구간을 난이도별로 조정한다.
- [ ] 이동과 회전 연출 시간을 조정해 VR 멀미를 줄인다.
- [ ] 성공, 실패, 망 착지, 망 줍기 사운드와 햅틱을 추가한다.
- [ ] 목표 칸, 선택 위치, 성공 구간을 알리는 월드 UI를 개선한다.
- [ ] 실패 원인을 파워 부족, 파워 초과, 경계선 접촉, 다른 칸 착지로 구분해 표시한다.

### 기획서 기반 확장

- [ ] 입문, 발전, 심화 스테이지를 구성한다.
- [ ] 4칸 직선형 입문판과 8칸 비행기형 판을 분리한다.
- [ ] BPM에 맞춰 QTE 속도와 난이도를 변화시킨다.
- [ ] 변형 놀이판과 장애물을 추가한다.
- [ ] 자기 땅의 색상, 문양, 소유 표시를 강화한다.
- [ ] 전신 트래킹 기반 실제 스텝과 점프 체험 모드를 별도 모드로 검토한다.
- [ ] 실제로 숙여 망을 줍는 Pick-and-Place 모드를 별도 모드로 검토한다.
- [ ] 체험 결과 저장과 교육·전시 운영 화면을 추가한다.
