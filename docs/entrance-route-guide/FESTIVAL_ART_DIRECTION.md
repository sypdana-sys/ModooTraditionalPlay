# 잔치마을 길 안내 — 배치·재질 명세

사용자 지정 방향 반영: 2026-09-11. 이 문서는 다음 제작 기준이며, 에셋 도입·배치 완료 보고가 아니다.

## 연출 목표

마을 입구에서 잔치를 하는 집으로 초대받아 걸어가는 느낌을 만든다. 깃발의 반복과 색의 연결로 진행 방향을 읽게 하고, 천막과 생활 소품으로 비진행 공간의 경계를 표현한다. 군기와 영기는 사용하되 수량과 간격을 절제해 군영보다 마을 잔치가 먼저 읽히게 한다.

## 에셋별 역할

| 역할 | 사용자 지정 에셋 | 배치·재질 기준 |
|---|---|---|
| 길 안내·경계 | KCISA 수원화성 오방색 군기 | 입구와 길의 가장자리에서 진행로를 감싼다. 방향을 구분하는 표식으로 사용하며, 실제 유물 문양과 의미는 확인 후 유지한다. |
| 강조 지점 | KCISA 영기(令旗) | 입구의 주요 안내 지점 또는 잔치 공간 진입부에 소수 사용한다. 모든 깃발보다 높이거나 수량을 늘리는 대신 주변 여백으로 강조한다. |
| 반복 배치 | KHS Flag A/B/C | 길 가장자리에 형태를 섞어 반복한다. 시작 위치에서 다음 깃발이 보이도록 시야를 연결하고, 중앙 통행 공간과 안내판 앞은 비운다. |
| 비진행 방향 제한 | General's Tent 또는 Low-poly Medieval Tent | 이탈하기 쉬운 옆길·공터의 진입부에만 배치한다. 정상 진행로는 막지 않는다. 형태·문양이 한국 마을과 어울리는지 확인 후 둘 중 선택한다. |
| 천막 본체 재질 | Poly Haven Linen 계열 | 자연스러운 마·린넨 계열의 바탕으로 구성한다. 무광에 가까운 표면과 적절한 직조 크기를 사용하고, 실제 조명 아래에서 색과 거칠기를 확인한다. |
| 장식 재질 | Quatrefoil Jacquard / Crepe Satin | 천막 가장자리, 좁은 장식띠, 포인트 천 등에 제한적으로 사용한다. 자카드는 문양 강조, 새틴은 은은한 광택 표현을 맡긴다. |

## 배치 순서

1. 현재 Unity Scene에서 사용자 삭제 상태, 남은 EntranceFlag_L/R, XR Rig, Terrain, 미저장 변경을 재확인한다. 삭제한 비교용 깃발은 복구하지 않는다.
2. 에셋 원본의 스케일·피벗·천과 깃대의 재질 슬롯·Collider·UV·라이선스를 확인한다. 기존 KHS 환경을 재Import하지 않는다.
3. 입구의 진행로 양옆에 깃발을 배치해 시작 방향을 표시한다. 안내판 문구와 화살표가 가려지지 않게 한다.
4. 강조 지점에 영기를 소수 배치하고, KHS Flag A/B/C로 입구 첫 구간의 시각적 연결을 만든다. 고정 수량보다 실제 시야·통행 폭을 기준으로 조정한다.
5. 비진행 방향에 필요한 경우에만 천막을 둔다. 보이는 기둥·본체와 일치하는 Collider를 사용한다.
6. Linen 본체와 자카드·새틴 장식의 대비를 Scene View 및 시작 카메라에서 확인하고, 확정한 배치와 재질을 로그에 기록한다.

## 재질·보존 기준

- Unlit 적용은 사용자 사전 확인이 필요하다. 어두운 부분을 해결하려고 조명 반응을 임의로 바꾸지 않는다.
- `Unreal/PBR_Shaders` 재사용 시 Albedo·Normal·Metallic·Roughness·AO 연결과 채널 의미를 확인한다. 천의 무늬 크기, 앞뒤 렌더링, UV 및 Tangent를 검증한다.
- 제공받은 Quatrefoil Jacquard / Crepe Satin 자료는 `Assets/RouteGuide/Entrance/FabricSamples/`에 있다. 현재 시험 재질을 최종 적용하기 전 실제 모델의 UV에 맞게 확인한다.
- 신규 외부 에셋 사용은 이번에 사용자가 지정한 모델과 재질 범위로 한정한다. 정확한 출처와 라이선스, 출처 표기 요구 사항을 기록한다.
- 대상은 `Assets/Scenes/main_playoursound.unity`. XR Transform·이동 설정, Terrain, 건축물, 전체 Lighting, 게임 로직 보존. 별도 Scene 백업 파일 생성 금지.

## 도입 전 확정할 사항

- KCISA 오방색 군기와 영기의 정확한 개별 모델 및 색상 구성.
- KHS Flag A/B/C의 정확한 다운로드 링크 또는 로컬 파일 경로.
- General's Tent / Low-poly Medieval Tent 중 실제 형상 확인 후 선택. 이름만으로 특정 제작자의 모델을 확정하지 않는다.
- Poly Haven Linen의 정확한 소재명과 다운로드 자료.

현재 위 항목들은 제작 후보이며, 모두 확보·Import된 상태가 아니다. Sketchfab 로그인은 확인되었으나 모델 다운로드 완료로 간주하지 않는다.

## 다음 범위와 검증

이번 기준은 우선 입구 첫 구간에 적용한다. 전체 경로를 확장할 때의 목적지는 장구 `AllLevel/Door01k (3)`, 사방치기 `AllLevel/Door01k (7)`이다. 전체 경로·분기 구현은 별도 작업 범위로 다룬다.
